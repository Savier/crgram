# crgram

Помощник для Android-игры «Cryptogram: letters and numbers»: снимает экран по adb
(или берёт готовый скриншот), распознаёт поле и даёт интерактивно подбирать буквы.

```sh
uv run crgram                            # TUI, экран с телефона по adb
uv run crgram -i samples/screen_01.png   # TUI по готовому скриншоту
uv run crgram board.toml                 # TUI по файлу поля
uv run crgram -w 2                       # авто-обновление каждые 2 с (для файла — при изменении)

uv run crgram scan [-i FILE] -o board.toml   # распознать в файл поля
uv run crgram check board.toml [--fix]       # проверить файл после ручной правки
uv run crgram shot out.png                   # сохранить скриншот с телефона
```

Распознавание и решение можно разделить: `scan` пишет файл поля, его можно поправить
руками и открыть в TUI. В TUI Ctrl+S сохраняет поле вместе с догадками
(в файл поля, в `-o FILE` или в `board.toml`).

## Файл поля

```toml
source = "samples/screen_01.png"

board = """
*_16 # _21 , | _3 Т20 _32 | _21 _30 _32 | З26 _13 # _18 ,
[ОБЩЕСТВЕННЫМ] | Д _21 # _6 # .
"""

[guesses]
16 = "Ж"
```

Строка — строка поля на экране, `|` разделяет слова, пробел — клетки:

| Запись | Клетка |
|---|---|
| `_16` | пустая, код 16 |
| `*_16` | выбранная в игре |
| `Т20` | открытая буква с кодом |
| `Д` | открытая буква, код скрыт (все такие буквы открыты) |
| `Т?20` | буква распознана OCR, не подтверждена |
| `#` | замок |
| `,` `.` `—` `!` … | пунктуация |
| `[СЛОВО]` | слово-подсказка целиком |

Догадки хранятся в `[guesses]` (`16 = "Ж"`), буквы в замках — в `[locks]`
с ключом «номер слова.номер клетки», считая с 1 и включая знаки препинания: `"3.2" = "А"`.

Для foldable-устройств дисплей выбирается автоматически (первый не чёрный), либо `-d N`.

## Управление в TUI

| Клавиша | Действие |
|---|---|
| ←→↑↓ | перемещение по клеткам |
| буква | назначить букву коду клетки (латиница переводится по раскладке ЙЦУКЕН) |
| буква на открытой клетке | исправить распознавание (символ запоминается) |
| буква на замке | догадка только для этой клетки (код замка неизвестен) |
| цифры, затем Enter | задать клетке код: снять замок или исправить номер (Esc — отмена) |
| `#` | пометить клетку замком |
| Enter | подтвердить распознанную букву (жёлтые — непроверенные) |
| Backspace / Delete | стереть догадку (или цифру набираемого кода) |
| Tab | следующая пустая клетка |
| Ctrl+Z / Ctrl+L | отменить (и правки кодов) / сбросить все догадки |
| Ctrl+S | сохранить поле и догадки |
| Ctrl+R, F5 / F6 | пересканировать / авто-обновление |

## Распознавание

- `vision/layout.py` — геометрия: белые плашки слов, слоты (пустая/выбранная клетка,
  буква, замок, пунктуация), цифры кода. Пороги относительны высоте плашки, цвет фона не важен.
- `vision/glyphs.py` — сопоставление символов с выученными образцами (шрифт один).
- `vision/ocr.py` — запасной OCR через `tesseract` (`brew install tesseract tesseract-lang`):
  цифры по нему обучаются автоматически, буквы требуют подтверждения в TUI.

Выученные образцы хранятся в каталоге данных пользователя (`--data-dir` или `CRGRAM_DATA_DIR`).
